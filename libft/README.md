# Description

Make our own library from scratch, using c for future projects authorizing us to include libft.
This project is made to understand basics concepts of C programming by reimplementing basics functions. It also helped to understand the concept of linked list.

## Description of the library created for this project

- libft.a
Includes:

ft_isascii ft_isdigit ft_isprint ft_itoa ft_memchr
ft_memcmp ft_memcpy ft_memmove ft_memset ft_putchar_fd
ft_putendl_fd ft_putnbr_fd ft_putstr_fd ft_split
ft_strchr ft_strdup ft_striteri ft_strjoin ft_strlcat
ft_strlcpy ft_strlen ft_strmapi ft_strncmp ft_strnstr
ft_strrchr ft_strtrim ft_substr ft_tolower ft_toupper
ft_lstnew ft_lstadd_front ft_lstadd_back ft_lstlast
ft_lstsize ft_lstdelone ft_lstclear ft_lstiter ft_lstmap

# Instructions

Generate the library using the makefile:
```bash
make
```
